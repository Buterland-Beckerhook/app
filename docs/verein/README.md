# Vereinswissen

Gesammeltes Wissen über den Schützenverein Buterland-Beckerhook e.V. – als Quelle für
Seiten und Artikel auf der Website und als Gedächtnis für alles, was in keinem Artikel
steht. Deutsch, weil der Inhalt deutsch ist.

Regeln:

- **Nichts erfinden.** Unbekanntes bleibt `?` oder `[PLATZHALTER]`; jede Datei nennt
  ihre Quellen.
- Widersprüche zwischen Quellen werden notiert, nicht stillschweigend aufgelöst.
- Personenbezogene Daten lebender Mitglieder (Geburtsdaten, Adressen) gehören erst nach
  Rücksprache auf die Website.
